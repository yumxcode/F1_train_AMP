AgiBot X1 真机部署：基于 PACE 的系统性参数辨识方案

参考文献：Bjelonic et al., "Towards bridging the gap: Systematic sim-to-real transfer for diverse legged robots", arXiv:2509.06342, 2025

一、为什么用 PACE 替代当前 DR 方案

❌ X1 当前方案（宽范围 DR）

  • Kp × [0.8, 1.2]，Kd × [0.8, 1.2]
  • lag_timesteps [5, 40]（8倍宽度）
  • joint_friction [0.01, 1.15]
  • 策略被迫学会在极宽参数范围下生存 → 保守、僵硬
  • 无法消除系统性偏差，只能覆盖

✅ PACE 方案（精确辨识）

  • 辨识出精确的 I_a, d, τ_f, q̃_b, T_d
  • 仿真与真机轨迹 MSE 最小化
  • 策略在精确模型中训练 → 不需要动力学 DR
  • 只保留任务层 DR（地形、推力）
  • ANYMAL 上 CoT 降低 32%，速度提升至 3 m/s
核心思想：PACE 将"参数不确定性"从训练时的随机化转移到部署前的精确辨识。辨识只需 ~20s 的编码器数据（无需力矩传感器），用 CMA-ES 进化优化在 4096 个并行仿真环境中拟合真实轨迹，10~24 小时收敛（单张 RTX 3080）。

二、X1 的参数向量定义

对于 X1 的 12 个腿部关节（左右各 6 个），PACE 辨识的参数向量为：

\[ \mathbf{p} = [\mathbf{I}_a,\; \mathbf{d},\; \boldsymbol{\tau}_f,\; \tilde{\mathbf{q}}_b,\; T_d]^\top \in \mathbb{R}^{4 \times 12 + 1 = 49} \]
参数含义X1 当前对应项典型量级（参考 ANYmal）
\(I_a\)（每关节）等效转动惯量（含齿轮箱折算）未建模，在 DR 中隐含1~10 × 10⁻² kg·m²
\(d\)（每关节）粘性阻尼系数joint_damping DR [0.3,1.5]0.1~5 N·m·s/rad
\(\tau_f\)（每关节）库仑摩擦力矩joint_friction DR [0.01,1.15]0.001~0.1 N·m
\(\tilde{q}_b\)（每关节）关节零位偏置motor_offset DR [-0.035,0.035]-0.02~0.02 rad
\(T_d\)（全局）通信+推理总延迟lag_timesteps DR [5,40]×1ms7.5 ms（ANYmal实测）
⚠️ 重要：PD 增益不参与辨识。由式 \(u_c \{I_a, d, P_\tau, D_\tau\}\) 的尺度不变性（论文 Eq.7），Kp/Kd 与 I_a, d 存在共线性，同时拟合会导致非唯一解。辨识时 Kp/Kd 固定为已知值。

三、整体流程

【Stage 1】硬件准备 机器人底座固定 + 腿部悬空，确保无地面接触 ↓ 【Stage 2】Chirp 数据采集 以 chirp 信号激励所有关节，记录编码器位置（1000 Hz） ↓ 【Stage 3】CMA-ES 参数辨识 在 4096 个并行仿真中最小化真实与仿真轨迹的 MSE ↓ 【Stage 4】辨识验证 用独立 chirp 序列验证，绘制相轨迹对比图 ↓ 【Stage 5】策略重训练 用辨识参数替换 DR，仅保留任务层随机化 ↓ 【Stage 6】落地步态验证 零样本真机部署，测量速度跟踪误差和步态周期

四、Stage 1：硬件准备（固定底座，腿部悬空）

4.1 实验装置要求

这是 PACE 方案的核心前提条件，论文称之为 "fixed base, no contacts (legs free in air)"：

  • 底座刚性固定：将 X1 躯干用螺栓固定在测试台架上，或用4个支撑点顶住底部，确保 base_link 完全静止。
  • 腿部完全悬空：所有12个关节可以自由运动，不与地面或其他物体接触。台架高度需保证腿部最大运动范围内无碰撞。
  • 消除交叉耦合：悬空状态下，每条腿的动力学仅受自身关节和固定底座影响，消除了腿间接触力的相互干扰。
为什么必须悬空？落地状态下，地面反力是未知的外力，会混入辨识信号中，使 I_a 和 d 的估计产生系统性偏差。悬空状态下，关节运动仅受重力（已知）和自身动力学影响，辨识问题是适定的。
4.2 固件模式确认

论文强调：辨识阶段和部署阶段必须使用完全相同的固件补偿模式（cogging 补偿、摩擦观测器等）。若辨识时启用了补偿，部署时也必须启用。否则补偿引入的"虚拟惯量"会产生无法消除的系统误差。

对于 X1，请确认并记录：

  • 电机驱动器固件版本
  • 是否启用 cogging 补偿
  • 是否启用摩擦前馈观测器
  • 电流环带宽设置（影响等效力矩追踪延迟）

五、Stage 2：Chirp 信号数据采集

5.1 激励信号设计

PACE 使用 chirp（线性调频）信号而非阶跃信号，原因是 chirp 能在一次实验中覆盖完整频率范围，信息量远高于单频激励。

激励频率范围：从 f_min = 0.1 Hz 到 f_max，X1 的策略频率为 100 Hz，Nyquist 频率为 50 Hz。但机械结构刚度约束通常限制实际激励在 10 Hz 以内（论文建议覆盖步态最高频率的2倍，X1 步态约 1.43 Hz，因此至少覆盖 3 Hz，建议取 10 Hz）。

\[ \hat{q}_j(t) = q_{j,0} + A_j \sin\!\left(2\pi \left(f_0 t + \frac{f_1 - f_0}{2T}t^2\right)\right) \] X1 参数：\(f_0=0.1\,\text{Hz},\; f_1=10\,\text{Hz},\; T=20\,\text{s},\; A_j = 0.3\,\text{rad}\)
⚠️ 论文建议对称运动（左右腿对称）以消除净底座力矩。X1 为双足机器人，采集时左右同名关节同步施加反向对称 chirp，例如左髋 pitch +A·sin，右髋 pitch −A·sin。
5.2 采集脚本
import numpy as np
import time, csv

def generate_chirp(f0, f1, T, amplitude, dt=0.001):
    """生成线性调频 chirp 序列"""
    t = np.arange(0, T, dt)
    phase = 2 * np.pi * (f0 * t + (f1 - f0) / (2 * T) * t**2)
    return t, amplitude * np.sin(phase)

def collect_chirp_data(robot_interface, joint_names, amplitude=0.3,
                        f0=0.1, f1=10.0, duration=20.0, dt=0.001):
    """
    对所有关节同时施加 chirp，采集编码器数据
    robot_interface: 机器人低层控制接口
    joint_names: 关节名列表（与 x1_config 顺序一致）
    """
    t_arr, chirp = generate_chirp(f0, f1, duration, amplitude, dt)
    n_joints = len(joint_names)

    # 对称符号：左腿正相，右腿反相（抵消净力矩）
    signs = np.array([1, 1, 1, 1, 1, 1,   # 左腿 6 关节
                     -1,-1,-1,-1,-1,-1])    # 右腿 6 关节（对称）

    q0 = robot_interface.get_positions()    # 当前零位
    kps = np.array([30, 40, 35, 100, 35, 35]*2)   # 与 x1_config 一致
    kds = np.array([ 3,  3,  4,  10, 0.5, 0.5]*2)

    log = []  # [t, q_target(12), q_real(12)]

    for i, t in enumerate(t_arr):
        q_target = q0 + signs * chirp[i]
        q_real   = robot_interface.get_positions()
        dq_real  = robot_interface.get_velocities()

        tau = kps * (q_target - q_real) - kds * dq_real
        tau = np.clip(tau, -robot_interface.tau_limits, robot_interface.tau_limits)
        robot_interface.send_torques(tau)

        log.append(np.concatenate([[t], q_target, q_real]))
        time.sleep(dt)

    return np.array(log)   # shape: [T/dt, 1 + 12 + 12]

# 采集 3 组（用于训练），1 组（用于验证）
for trial in range(4):
    log = collect_chirp_data(robot, joint_names)
    np.save(f'chirp_data_trial{trial}.npy', log)
    time.sleep(3.0)   # 等待关节静止

六、Stage 3：CMA-ES 参数辨识

6.1 仿真回放原理

辨识的核心是：将采集到的真实关节目标轨迹 \(\hat{q}^{\text{real}}\) 以相同的速率输入到仿真中，用一组参数 \(\mathbf{p}\) 驱动仿真，比较仿真输出位置 \(q^{\text{sim}}\) 与真实位置 \(q^{\text{real}}\) 的差异：

\[ \ell(\mathbf{p}) = \frac{1}{k}\sum_{i=1}^{k} \| q_i^{\text{real}} - q_i^{\text{sim}}(\mathbf{p}) \|^2 \] \[ \mathbf{p}^* = \arg\min_{\mathbf{p}}\; \mathbb{E}[\ell(\mathbf{p})] \]

关键：仿真使用的控制律与真机完全一致：

\[ \tau_t = P_\tau(\hat{q}_t + q_0 - q) - D_\tau \dot{q} \] 其中 \(\hat{q}_t\) 是延迟 \(T_d\) 后的目标位置（ZOH 方式保持）
6.2 IsaacGym 并行仿真辨识脚本（框架）
import torch
import numpy as np
from cmaes import CMA   # pip install cmaes

# ---- 参数边界（参考 PACE 论文 Table 5 及 X1 物理约束）----
PARAM_BOUNDS = {
    'I_a':   (1e-4,  0.5),    # kg·m²，每关节
    'd':     (0.01,  10.0),   # N·m·s/rad，每关节
    'tau_f': (0.001, 2.0),    # N·m，每关节（库仑摩擦）
    'q_b':   (-0.05, 0.05),   # rad，每关节（零位偏置）
    'T_d':   (0.001, 0.050),  # s，全局延迟
}
N_JOINTS = 12
N_PARAMS = 4 * N_JOINTS + 1  # = 49

def params_to_vector(I_a, d, tau_f, q_b, T_d):
    return np.concatenate([I_a, d, tau_f, q_b, [T_d]])

def vector_to_params(p):
    n = N_JOINTS
    return p[:n], p[n:2*n], p[2*n:3*n], p[3*n:4*n], p[4*n]

# ---- 仿真回放损失（在 IsaacGym 中并行运行 N=4096 个环境）----
def simulate_and_score(p_batch, chirp_targets, chirp_real, sim_dt=0.001, N_envs=4096):
    """
    p_batch: [N_envs, 49] 参数矩阵（CMA-ES 采样的一批参数）
    chirp_targets: [T, 12] 真机目标关节角序列
    chirp_real: [T, 12] 真机实际关节角序列
    返回: [N_envs] 每组参数的 MSE 损失
    """
    T = chirp_targets.shape[0]
    losses = torch.zeros(N_envs, device='cuda')

    # 初始化仿真状态
    q_sim   = torch.zeros(N_envs, N_JOINTS, device='cuda')
    dq_sim  = torch.zeros(N_envs, N_JOINTS, device='cuda')

    I_a   = torch.tensor(p_batch[:, :N_JOINTS],           device='cuda')
    d     = torch.tensor(p_batch[:, N_JOINTS:2*N_JOINTS],  device='cuda')
    tau_f = torch.tensor(p_batch[:, 2*N_JOINTS:3*N_JOINTS],device='cuda')
    q_b   = torch.tensor(p_batch[:, 3*N_JOINTS:4*N_JOINTS],device='cuda')
    T_d   = torch.tensor(p_batch[:, 4*N_JOINTS],          device='cuda')  # [N_envs]

    delay_steps = (T_d / sim_dt).long()   # 延迟步数，每个 env 可不同

    kp = torch.tensor([30,40,35,100,35,35]*2, device='cuda', dtype=torch.float)
    kd = torch.tensor([ 3, 3, 4,  10, .5,.5]*2, device='cuda', dtype=torch.float)
    q0 = torch.tensor(chirp_real[0], device='cuda', dtype=torch.float)

    for i in range(T):
        # 取延迟后的目标（ZOH）
        delayed_idx = torch.clamp(i - delay_steps, 0, T-1)   # [N_envs]
        q_target = torch.tensor(chirp_targets[delayed_idx.cpu().numpy()],
                                device='cuda', dtype=torch.float)  # [N_envs, 12]

        # PD 控制律（与 sim2sim.py 一致）
        tau = kp * (q_target + q0 - q_sim + q_b) - kd * dq_sim

        # 库仑摩擦
        tau_friction = tau_f * torch.sign(dq_sim)

        # 单关节动力学：I_a * ddq = tau - d * dq - tau_friction
        ddq = (tau - d * dq_sim - tau_friction) / I_a

        # 欧拉积分
        dq_sim = dq_sim + ddq * sim_dt
        q_sim  = q_sim  + dq_sim * sim_dt

        # 累计损失
        q_real_t = torch.tensor(chirp_real[i], device='cuda', dtype=torch.float)
        losses += ((q_sim - q_real_t)**2).mean(dim=1)

    return (losses / T).cpu().numpy()

# ---- CMA-ES 主循环 ----
def run_cmaes(chirp_targets, chirp_real, n_iterations=100):
    # 初始参数猜测
    p0 = np.array([0.02]*12 + [1.0]*12 + [0.01]*12 + [0.0]*12 + [0.0075])
    sigma0 = 0.1

    optimizer = CMA(mean=p0, sigma=sigma0, bounds=np.array(
        [(l,u) for k,(l,u) in PARAM_BOUNDS.items() for _ in range(N_JOINTS if k!='T_d' else 1)]
    ))

    for iteration in range(n_iterations):
        # 采样一批参数
        solutions = [optimizer.ask() for _ in range(optimizer.population_size)]
        p_batch = np.array(solutions)  # [pop_size, 49]

        # 并行仿真评估
        losses = simulate_and_score(p_batch, chirp_targets, chirp_real)

        # 告知 CMA-ES 结果
        optimizer.tell([(sol, loss) for sol, loss in zip(solutions, losses)])

        best_loss = min(losses)
        print(f"Iter {iteration:3d} | best_loss = {best_loss:.6f}")

        if best_loss < 1e-5:
            print("收敛！")
            break

    return optimizer.mean   # 最优参数 p*

7.2 Delta 相轨迹验证

PACE 论文 Figure 1c 使用"Delta 相轨迹"（\(\Delta q\) vs \(\Delta \dot{q}\)）直观显示仿真与真实的差距。越接近原点，模型越精确：

def plot_delta_phase_portrait(p_star, chirp_targets, chirp_real, joint_idx=3):
    """绘制膝关节的 Delta 相轨迹（参考论文 Figure 1c）"""
    q_sim  = replay_simulation(p_star, chirp_targets)
    dq_sim = np.gradient(q_sim, 0.001, axis=0)
    dq_real = np.gradient(chirp_real, 0.001, axis=0)

    dq = q_sim[:, joint_idx]  - chirp_real[:, joint_idx]   # 位置误差
    ddq = dq_sim[:, joint_idx] - dq_real[:, joint_idx]     # 速度误差

    plt.figure(figsize=(6, 6))
    plt.scatter(dq, ddq, s=1, alpha=0.3, c='green', label='PACE')
    plt.axhline(0, color='k', lw=0.5); plt.axvline(0, color='k', lw=0.5)
    plt.xlabel('Δq [rad]'); plt.ylabel('Δq̇ [rad/s]')
    plt.title('Delta Phase Portrait (closer to origin = better)')
    plt.legend(); plt.tight_layout()
    plt.savefig('delta_phase.png', dpi=150)

9.2 步态周期测量（结合前文方法）

使用足端高度法（正运动学）测量实际步态周期，与 cycle_time = 0.7 s 对比：

def measure_gait_cycle_on_ground(log_q, t, L_thigh=0.35, L_shank=0.30):
    """从落地行走的关节角度记录中测量步态周期"""
    # 左脚足端高度（相对底座）
    hip_p = log_q[:, 0]; knee_p = log_q[:, 3]; ank_p = log_q[:, 4]
    z_foot_left = -(L_thigh*np.cos(hip_p) + L_shank*np.cos(hip_p - knee_p))

    # 落地事件：足端高度低于阈值 + 从高到低（下降沿）
    stance = z_foot_left < -0.60
    landings = np.where(np.diff(stance.astype(int)) == 1)[0]   # 支撑相开始

    if len(landings) >= 2:
        # 同侧相邻两次落地 = 完整步态周期（左+右各一步）
        cycles = np.diff(t[landings])
        print(f"实测步态周期: {np.mean(cycles):.3f} ± {np.std(cycles):.3f} s")
        print(f"设计值 cycle_time=0.7s，偏差: {abs(np.mean(cycles)-0.7)/0.7*100:.1f}%")
