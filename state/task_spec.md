## 1. Project Goal

Convert `F1_train_AMP` from a plain PPO walking project into a fully trainable,
evaluable, and exportable AMP (Adversarial Motion Priors) project; complete F1 walk
motion retargeting and produce reliable expert motion data; finally train F1 to walk
stably with a reference gait. The work proceeds as a hard, ordered progression of
phases and gates:

`amp_conversion` (Gate A) → `motion_retargeting` (Gate B) → `amp_training` (Gate C) → `completed`

Only when the phase's gate variable (`A_healthy` / `B_healthy` / `C_healthy`) is `true`
may the next phase begin. Gates may not be skipped by editing state files or lowering
acceptance thresholds.

## 2. Milestone — Gate A (`amp_conversion`, AMP engineering)

Goal: realize a complete AMP closed loop on the current project.

- [ ] Static checks / import / config parsing pass
- [ ] One bounded smoke train with small data + small env: AMP modules execute and
      parameters update by a bounded amount; training log shows an independent
      discriminator and a style reward
- [ ] expert/policy transition schema auto-comparison PASS (no NaN/Inf, empty set,
      out-of-range index, or wrong broadcasting)
- [ ] checkpoint save → resume and play each verified at least once
- [ ] AMP task is not a renamed PPO task (independent discriminator + style reward
      evidence in logs)
- [ ] `amp_contract.json` produced; verification commands/logs/results written to
      findings
- [ ] Minimal plain-PPO baseline preserved for regression / AMP-gain comparison

Pass criteria → `A_healthy = true`. Fail → `stale_countA += 1`; `stale_countA >= 10`
→ `error` (halt). Unrecoverable execution/data/external failure → `error` (halt).

## 3. Milestone — Gate B (`motion_retargeting`, F1 walk retargeting)

Goal: produce verified F1 expert motion data via GMR-style retargeting (X1 adaptation).

- [ ] Reference walk source recorded (hash, fps, clip range, left/right contact info)
- [ ] Explicit joint mapping from F1 URDF/MJCF to AMP loader order (no dict-order /
      hardcoded foreign indices)
- [ ] Per-clip checks: joint name 1:1, dims/order consistent; root height/pose/
      direction sane; contact timing matches reference; support-foot slip / penetration
      / float / knee back-fold / self-collision within thresholds; loop continuity
- [ ] At least one clip passes full MuJoCo (or equivalent) kinematic replay + quantitative
      acceptance
- [ ] AMP loader statistics match retarget output; disqualified clips isolated with reasons
- [ ] Visualization video, numerical report, and final expert motion manifest produced
- [ ] GMR reference (Roboparty/GMR) cloned into project before this work

Pass criteria → `B_healthy = true`. Fail → `stale_countB += 1`; `stale_countB >= 10`
→ `error` (halt).
